# أثر — موقع تراثي تجريبي

موقع عربي متجاوب على GitHub Pages، يضم معرض منتجات، تأثيرات Parallax، ومشهد زخارف دائري، وتأثير توسع صورة مرتبط بالتمرير مستلهم من أسلوب Halde على Framer.

## الصفحات

- `index.html` — الموقع العام.
- `admin.html` — لوحة تحرير محلية للتجربة، وليست لوحة مدير آمنة.
- `catalog.json` — بيانات المنتجات والنصوص المنشورة للزوار.
- `assets/` — صور المنتجات والشعار والزخارف.

## استخدام لوحة التحكم

1. افتح `admin.html` وعدّل المنتج أو النصوص والصور.
2. افتح «معاينة التعديلات» للتأكد من شكلها على **نفس المتصفح**.
3. افتح «النشر والنسخ» ونزّل `catalog.json`.
4. استبدل ملف `catalog.json` في جذر المستودع بالمخرَج الجديد، ثم انتظر نشر GitHub Pages.

> **هام:** GitHub Pages يستضيف صفحات ثابتة. التعديل داخل `admin.html` يحفظ مسودة في LocalStorage على الجهاز فقط، ولا ينشر للمستخدمين الآخرين. لا يوجد تسجيل دخول آمن أو إدارة طلبات مشتركة أو قاعدة بيانات. لا تخزّن أسرارًا أو بيانات عملاء هنا. لإدارة مشتركة وآمنة يلزم Backend وقاعدة بيانات وصلاحيات.

## الصور

الزخرفتان الشفافتان `motif-history-cutout.webp` و`motif-gold-cutout.webp` **معالجات بصرية مولدة** بالاستناد إلى الصور المرجعية المرسلة، وليستا صورة وثائقية أصلية ولا صورة مطابقة مضمونة للمنتج. بقية صور المنتجات مستخلصة من صور البراند المرسلة. صور العمارة المستضافة خارجيًا موثقة في `PHOTO_SOURCES.md`.

## النشر

GitHub Pages من الفرع `main` والمجلد `/ (root)`.

## تأثير التمرير الجديد

- الصورة تبدأ في إطار صغير مستدير الحواف، ثم تتمدد إلى عرض الشاشة مع التمرير.
- العنوان العربي ينفصل على جانبي الصورة، وتظهر الكلمات في قسم البيان تدريجيًا.
- كود الحركة مكتوب خصيصًا لهذا المشروع، بدون نسخ ملفات القالب المدفوع أو أي مكتبة Framer.
- يتم إيقاف الحركة المعقدة تلقائيًا لمن يفضّل تقليل الحركة (`prefers-reduced-motion`).
- على الموبايل تتمدد الصورة بدون تمرير أفقي، ويظل شعار أثر منفصلًا في الشريط العلوي.


## واجهة التحميل الافتتاحية

تظهر عند دخول الموقع حركة دائرية صغيرة بشعار «أثر»، مع شريط تقدّم زخرفي، ثم تنتقل الصفحة بسلاسة. يمكن تخطيها، كما تتعطل عند تفضيل تقليل الحركة. الحد الأقصى لإخفائها تلقائيًا 4.2 ثوانٍ عند بطء الموارد. إعدادات التشغيل والمدة متاحة في **لوحة التحكم ← محتوى الصفحة**، ويتم نشرها ضمن `catalog.json`.

## لوحة التحكم المحسّنة

- واجهة تحكم متجاوبة للكمبيوتر والموبايل.
- إضافة/تعديل/حذف/إخفاء المنتجات، تغيير ترتيبها، الصور والأسعار والتصنيفات.
- مكتبة صور تربط كل صورة بالمنتج القابل للتعديل.
- تحرير نصوص الهيرو ورابط إنستجرام، وضبط مقدمة التحميل.
- حفظ محلي تلقائي، ومعاينة المسودة عبر `index.html?preview=1`، واستيراد وتصدير `catalog.json`.
- **لا يوجد نشر مباشر أو حساب مدير آمن** على GitHub Pages؛ يجب رفع ملف `catalog.json` يدويًا إلى GitHub، أو ربط Backend بصلاحيات عند الانتقال للإنتاج.
