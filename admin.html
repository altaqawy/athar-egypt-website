النشر والنسخ الاحتياطي

ملف واحد يحمل كل المنتجات والنصوص وصور المنتجات الجديدة

  1. 1استخدم لوحة التحكم لإضافة المنتجات أو تغيير الأسعار، ثم اضغط تنزيل catalog.json.
  2. 2افتح مستودع أثر على GitHub، واستبدل ملف catalog.json الموجود في الجذر بالملف الجديد، أو ارفعه هنا كي أتولى تحديثه.
  3. 3بعد اكتمال GitHub Pages، تظهر التغييرات للزوار. معاينة المتصفح المحلية لا تنشر أي شيء بمفردها.
عن الأمانهذه الواجهة لا تطلب كلمة مرور لأنها مجرد مُحرِّر بيانات محلي. لا تضع فيها كلمات مرور أو مفاتيح GitHub. الإدارة الحقيقية المتزامنة بين الأجهزة تتطلب ربطًا آمنًا بخدمة خلفية وقاعدة بيانات.
